MyLearner 폐쇄망 점검 도구 (결과 코드 판 1)

[들어 있는 것]
  ai_probe.py          사내 AI 서버와 모델을 잽니다(Python 3.9 이상, 설치할 것 없음)
  browser_probe.html   크롬의 저장소와 기능을 잽니다(더블클릭)
  README_KO.txt        이 안내

[순서] 자세한 순서와 확인할 것은 함께 받은 체크리스트(docs/P1_체크리스트_Probe.md)를 따릅니다.
  1. 이 폴더에서 명령 프롬프트(cmd)를 엽니다. 탐색기 주소 칸에 cmd 를 치고 엔터를 누르면 됩니다.
  2. AI 점검:        py -3 ai_probe.py
     - 서버 주소를 물으면 적습니다(예: http://192.0.2.10:8000). 키는 적어도 화면에 보이지 않습니다.
     - 다른 서버도 차례로 적고, 다 했으면 빈 줄에서 엔터를 누릅니다.
  3. 브라우저 점검:  MWL 화면을 모두 닫고 browser_probe.html 을 크롬으로 엽니다.
  4. 서버 모드 점검: py -3 ai_probe.py --serve-test
  5. 화면의 "결과 코드" 줄들을 그대로 옮겨 적어 전합니다. 줄 끝의 /두 글자는 검사합입니다.

[지키는 것]
  - 결과 코드와 결과 파일(ai_probe_result_*.txt)에는 주소, IP, 포트, 키가 들어가지 않습니다.
  - 키는 화면에 찍지 않고 어디에도 남기지 않습니다.
  - 리다이렉트를 따르지 않습니다(키가 다른 서버로 가지 않게).
  - 키는 서버가 JSON 으로 키를 요구할 때만 보냅니다. http 주소가 프록시를 거치면 키를 프록시로 보내지 않습니다.
  - py 명령이 없으면 python ai_probe.py 로 실행합니다. IDLE 이 아니라 명령 프롬프트에서 실행합니다.
  - 점검이 끝나면 browser_probe.html 의 "흔적 지우기" 를 누릅니다.
