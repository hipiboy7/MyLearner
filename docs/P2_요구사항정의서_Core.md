## 1. 목적

Phase 3 화면이 올라설 **계산 한 벌(JS)과 파일 형식**을 만든다. 화면은 없다. 끝나면 다음이 시험으로 증명돼 있다.

1. 기록은 기기별 사건 목록이고, 여러 파일을 어떤 순서로 몇 번 합쳐도 결과가 같고 사건이 하나도 사라지지 않는다(S3)
2. 두 기기가 같은 카드를 따로 복습해도 간격이 부풀지 않는다(늦은 복습 규칙)
3. SM-2·하루 계획·숙련도·통계가 MWL 골든 벡터를 그대로 통과한다
4. 강의 마크다운을 화면이 직접 그리고, MWL 135과와 같은 HTML 을 내며, XSS 사례 모음을 막는다
5. MWL 미들웨어 과정이 과정 파일 하나로 바뀌고, MWL 진도(스키마 1·2)가 사건으로 바뀌어 같은 카드의 다음 복습일이 같다(S5)

## 2. 범위

- `web/core/*.js` — 상수, 날짜, 해시, 과정 파일 검사, 사건·기록 파일·합치기·다시 계산, SM-2, 하루 계획, 숙련도, 통계(MWL `summary` 이식), 채점(퀴즈·실습·드릴), 렌더러, MWL 진도 변환

## 5. 제약

- MWL·hub 는 읽기만 한다. 옮긴 코드의 머리에 출처와 기준 커밋을 적는다
