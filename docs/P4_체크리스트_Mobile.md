# P4 체크리스트 — 폰에서 배우기 + 합치기 (써 보기)

- 작성 2026-11-10 / 대응: [`P4_테스트결과서_Mobile.md`](P4_테스트결과서_Mobile.md), [`P4_설계서_Mobile.md`](P4_설계서_Mobile.md), [`P4_요구사항정의서_Mobile.md`](P4_요구사항정의서_Mobile.md)
- 순서대로 하고 칸마다 "하면 → 보여야 할 것"을 확인한다. 1 은 이 VM(MyLearner 저장소 `/data/projects/MyLearner`, 브랜치 `impl-phase4`), 2 는 폰(갤럭시 Z 폴드5 · S22 울트라), 3 은 내 PC(Windows · Chrome), 4 는 폐쇄망 PC 에서 한다. 폰 순서는 MWL `docs/checklist/android-app.md`(14칸)를 본떠 MyLearner 화면에 맞췄다
- 1 의 명령은 이 VM 에서 적은 그대로 실행해 확인했다(2026-11-10). 2~4 는 **미실행**이다 — 이 VM 의 에뮬레이터(Android 16 · API 36)와 헤드리스 Chromium 으로 같은 흐름을 확인했다(테스트결과서 1·8절). 실제 갤럭시·Windows·Chrome 은 이 체크리스트가 첫 시험이다
- Phase 4 를 `main` 에 병합하면 GitHub 릴리스 `v0.4.0` 에 APK·폐쇄망 zip·인터넷판 zip 이 올라간다(CLAUDE.md 7절 '릴리스'). 그 전에는 1 에서 만든 `dist/` 의 파일을 옮겨 쓴다

## 1. 묶음·APK 만들기 (이 VM)

- [ ] 하면: P3 체크리스트 1절의 과정 만들기 세 줄(`check_mwl_real.py`·`mylearner.convert.learn` 둘)로 `dist/courses/` 를 만든다
  → 보여야 할 것: `dist/courses/` 에 `mwl.course.json`·`mwm-app.course.json`·`llm-chat-agent.course.json`
- [ ] 하면: `python3 scripts/pack_app.py --edition closed`
  → 보여야 할 것: `만듦: …/dist/mylearner-closed-v0.4.0.tgz` 와 `만듦: …/dist/mylearner-closed-v0.4.0.zip`(폐쇄망 반입은 zip)
- [ ] 하면: `python3 scripts/pack_app.py --edition internet`
  → 보여야 할 것: `만듦: …/dist/mylearner-internet-v0.4.0.tgz`·`.zip`
- [ ] 하면: `bash scripts/build_android.sh`
  → 보여야 할 것: 끝에 `결과: dist/android/MyLearningPlatform-v0.4.0.apk`, `권한 없음(인터넷 권한 없음) · exported 구성요소 1(런처)`, `서명 인증서 SHA-256 7589128ce39f53ef32dfffa269405d8c07d625248273a23b50ce6d25e0a9b18c`(릴리스 키 — 2026-11-10 만듦)
- [ ] (서명 키 보관) 이 VM 계정 `~/.config/mylearner/` 의 `android-release.jks`·`android-release.pass` 두 파일을 **VM 밖 안전한 곳에 한 부** 둔다. `/data` 개인 폴더 사본은 이미 있다. 키를 잃으면 다음 판을 덮어 설치할 수 없어 폰의 앱을 지워야 하고 앱 안 기록이 사라진다(보류 결정 3)
- [ ] (시간이 되면) 하면: `bash scripts/verify.sh` → 보여야 할 것: `전체 통과 (23단계)`. 약 9분

## 2. 폰 — 갤럭시 Z 폴드5 · S22 울트라

### 2-1 받기·설치

- [ ] 하면: GitHub 앱(내 계정) → 저장소 → MyLearner → 릴리스 → `v0.4.0` → Assets → `MyLearningPlatform-v0.4.0.apk`(또는 VM 의 `dist/android/` 에서 옮긴 파일)
  → 보여야 할 것: 내 파일 → 다운로드 에 `MyLearningPlatform-v0.4.0.apk`(약 2.4 MB)
- [ ] 하면: 그 파일을 누른다 → "이 출처의 알 수 없는 앱" 창이면 [설정] → 이 출처 허용 → 뒤로 → [설치]. Play 프로텍트 창이면 [검사하지 않고 설치] 또는 [자세히] → [무시하고 설치]
  → 보여야 할 것: "앱이 설치되었습니다" → [열기]. 막히면 그 창의 문구를 그대로 적는다(갤럭시 '자동 차단'이면 설정 → 보안 및 개인정보 보호 → 자동 차단을 끄고 다시 — 메뉴 이름은 One UI 판마다 다르다 ⚠️)

### 2-2 처음 쓰기 — 인터넷 없이

- [ ] 하면: 비행기 모드를 켜고 앱 목록의 **MyLearningPlatform**(파란 바탕에 흰 M) 을 연다
  → 보여야 할 것: 오늘 화면, 왼쪽 위 `모바일판`, 메뉴 9개(오늘·복습·점검·오답노트·통계·회고·과정·용어·설정)가 두 줄로 다 보인다. **'다른 탭이 기록을 쓰고 있어…' 띠가 없다**(에뮬레이터에서 찾아 고친 것 — 트러블슈팅 T-014)
- [ ] 하면: 과정 → 보여야 할 것: 미들웨어 과정(135과)·MWM 미들웨어관리소 학습(45과)·llm-chat-agent 학습(9과). 표가 화면보다 넓으면 옆으로 넘겨 본다
- [ ] 하면: 오늘 → [강의 열기] → 끝까지 넘겨 [3 보통]
  → 보여야 할 것: 오늘로 돌아오고 띠 `… 마침 - 카드 N장이 복습 대기열에 들어갑니다`. 강의 글·표가 화면 밖으로 나가지 않는다
- [ ] 하면: [복습 시작] → [답 보기] → [알겠음] 을 세 장
  → 보여야 할 것: 1/N 이 늘고, 키보드 안내(`Space`·`1~4`)는 보이지 않는다(손가락 화면)

### 2-3 강제 종료 뒤에도 남는가

- [ ] 하면: 복습 한 장을 채점하자마자 최근 앱 화면에서 MyLearningPlatform 을 위로 밀어 지운다 → 아이콘으로 다시 켠다
  → 보여야 할 것: 방금 채점한 것까지 남아 있다(통계 ① 오늘 복습 수, 오늘 화면 '오늘 학습' 분). 기록은 앱 전용 파일에 바로 적힌다(FR-410 — 에뮬레이터에서 채점 0.1초 뒤 강제 종료로 확인)

### 2-4 폴드5 — 접기·펼치기 / S22 울트라

- [ ] 하면: (폴드5) 복습 중에 접고 펼친다. 가로로도 돌린다
  → 보여야 할 것: 같은 카드·같은 자리에 그대로(화면을 다시 만들지 않는다). 펼친 화면은 넓은 배치, 접은 화면은 좁은 배치
- [ ] 하면: 설정 → 맨 아래 '이 앱' 줄의 `화면 폭 N px` 를 접은 화면·펼친 화면·S22 울트라에서 각각 적는다
  → 보여야 할 것: 숫자 셋. **피드백 칸에 적어 주면** 화면 확인 폭(지금은 추정 344·690·390)을 고친다 ⚠️

### 2-5 통계·밝기·뒤로 가기

- [ ] 하면: 통계 → 보여야 할 것: 맨 위 범위 `이 폰에 모인 기록(이 폰 + 들여온 기록)`, ①~⑥ 절, 차트 글자가 읽힌다
- [ ] 하면: 설정 → 화면 → 밝기 '어둡게' → 보여야 할 것: 화면과 상태 표시줄이 함께 어두워진다
- [ ] 하면: 통계 화면에서 뒤로 가기 → 오늘 → 한 번 더 뒤로 가기
  → 보여야 할 것: 통계 → 오늘로 한 걸음, 오늘에서는 앱이 닫힌다

### 2-6 교환 파일 내보내기

- [ ] 하면: 설정 → 기록 → '다른 기기와 주고받기' → [교환 파일 파일로 저장] → 시스템 저장 창에서 다운로드 → [저장]
  → 보여야 할 것: 띠 `교환 파일 mylearner-exchange-<날짜>-<6자리>.zip(N줄) - 다른 기기의 …`, 내 파일 → 다운로드 에 그 zip
- [ ] 하면: [교환 파일 공유] → 카카오톡 '나와의 채팅'(또는 메일·드라이브)
  → 보여야 할 것: 공유 목록에 카카오톡이 있고 보내진다
- [ ] (선택 — 7일 뒤) 내보내지 않고 7일이 지나면 → 보여야 할 것: 오늘 맨 위에 '마지막 내보내기 N일 전' 띠(FR-413)

## 3. 내 PC — 폰 기록 합치기 (인터넷판 0.4.0)

- [ ] 하면: `mylearner-internet-v0.4.0.zip` 을 풀고 `MyLearner.cmd`
  → 보여야 할 것: 검은 창에 `MyLearner 0.4.0 인터넷판 - http://127.0.0.1:8770/?token=…`, Chrome 에 오늘 화면(P3 데이터 폴더를 옮겨 왔으면 앞 기록이 그대로)
- [ ] 하면: 폰이 보낸 교환 파일을 PC 에 받는다(카톡 PC·메일) → 설정 → [다른 기기 기록 합치기] → [교환 파일 고르기]
  → 보여야 할 것: 미리보기 — 파일(교환 파일 · 모바일판 0.4.0 · 만든 기기), 새로 더할 줄, 기기 표(폰 기기 · 학습일 범위), 과정마다 새 기록
- [ ] 하면: [백업하고 합치기] → 확인
  → 보여야 할 것: **'파일의 기록 N / N 이 이 기기 기록에 있습니다'**, 통계에 폰에서 한 복습이 더해진다
- [ ] 하면: 같은 파일을 한 번 더 고른다 → 보여야 할 것: `새로 더할 줄 0 - 이미 모두 있음`(멱등)
- [ ] (선택) 하면: 결과 화면 [이 들여오기 되돌리기] → 미리보기 → [백업하고 되살리기]
  → 보여야 할 것: 폰 줄만 빠지고 PC 에서 쓴 기록은 남는다. 설정 → 백업에서 '되살리기 전' 을 되살리면 다시 돌아온다
- [ ] 하면: PC 에서 복습 몇 장 → 설정 → [교환 파일 내려받기] → 그 zip 을 폰으로 보내 폰의 [다른 기기 기록 합치기]
  → 보여야 할 것: 폰에서도 N / N, 두 기기의 통계가 같아진다(왕복)

## 4. 폐쇄망 PC — 들여오기만 (폐쇄망판 zip)

- [ ] 하면: `mylearner-closed-v0.4.0.zip` 과 3에서 내려받은 교환 파일 zip 을 폐쇄망 PC 로 반입 → 폐쇄망판 zip 만 풀고 `MyLearner.cmd`
  → 보여야 할 것: `MyLearner 0.4.0 폐쇄망판 - http://127.0.0.1:8770/?token=…`, 왼쪽 위 `폐쇄망판`
- [ ] 하면: 설정 → 보여야 할 것: '이 판은 기록을 밖으로 내보내지 않습니다…' 와 [다른 기기 기록 합치기] 만 있고 내보내기·내려받기 단추가 없다
- [ ] 하면: [다른 기기 기록 합치기] → 교환 파일 zip 을 **풀지 않고** 고른다 → [백업하고 합치기]
  → 보여야 할 것: N / N. 오늘·통계에 폰·내 PC 의 기록이 함께 보인다(범위 `폐쇄망 안의 기록과 들여온 기록`)
- [ ] 하면: 다음 반입 때 같은 일을 되풀이한다 → 보여야 할 것: 새 줄만 더해지고, 폐쇄망 안에서 한 복습은 그대로 남는다
