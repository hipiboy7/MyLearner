## 3. 완성의 정의 (초안 — 착수 인터뷰에서 확정)

- S1 폐쇄망 PC 에서 문맥 길이보다 긴 사내 매뉴얼 한 권으로 과정을 만들어 **그날 복습까지** 한다.
- S2 AI 가 만든 강의의 모든 문장이 근거(자료 이름·절) 또는 ⚠️ 표시를 가진다.
- S3 폰 ⇄ 집 PC 왕복과 폐쇄망 반입을 반복해도 기록이 하나도 사라지지 않는다(자동 시험).
- S4 설치 0 — 압축 풀기·APK 설치만으로 시작한다.
- S5 MWL 에서 쌓은 진도가 이어진다(같은 카드의 다음 복습일이 같다).
- S6 Learn 자료(kids 제외)를 과정으로 가져와 폰에서 복습한다.
- S7 **통계 화면**이 과정별·전체로 학습량·복습 정답률·정착률·숙련도·연속 학습일·추이를 보여 준다(세 판 모두, 5.4).

### 4.2 Learn hub — 겹치는 것과 가져올 것 (`/data/projects/Learn/hub`, Phase 3/5)

- 콘텐츠 표준 v0(`/data/projects/Learn/CLAUDE.md` 4절): `content/index.md` 의 프로젝트 머리, 페이지마다 YAML 머리(`title`·`confidence`·`sources`·`updated` 필수), 카드 JSON. MyLearner 의 가져오기 형식으로 받는다. 표준의 주인은 hub·Learn 루트이고 MyLearner 는 따라간다.
- 기기별 사건 기록 `/data/projects/Learn/hub/src/learnhub/engine/events.py`: 사건 한 줄(JSON), (기기, 순번)으로 합치기, 같은 (기기, 순번)에 다른 줄이면 고정 규칙으로 한쪽을 고르고 충돌로 센다, 기기마다 순번 순서를 지키며 기기 사이는 UTC 시각으로 엮는다. **이식 후보**(5.3-2).
- hub 는 설치형(Python 3.11 가상환경·pip·MkDocs)이라 폐쇄망 PC·폰에서는 못 쓴다. 같은 자료를 hub 와 MyLearner 양쪽에서 복습하면 기록이 따로 쌓인다 → 한쪽에서만 복습하도록 안내한다.

### 4.3 폐쇄망 AI

- 두 서버·다섯 모델(2절). vLLM 은 OpenAI 호환 API(`/v1/chat/completions`·`/v1/models`)를 준다. 두 번째 서버의 서빙 방식은 모른다.
- MWL 실측(2026-09-24, 사내가 아닌 참조 프로젝트의 GPT-OSS-120B): Chat·Responses 형식 모두 됐다, 정리 한 건 2~4초, 추론 강도 `reasoning_effort` 는 low 가 알맞았고 `chat_template_kwargs` 안에 넣으면 무시됐다(MWL 트러블슈팅 T-007), 모델이 양식을 여러 개 보냈다(T-020), 그 게이트웨이는 브라우저 직접 호출(CORS)을 막았다.
- 문맥 길이·답 상한·속도·CORS 는 폐쇄망 안에서만 잴 수 있다 → 첫 산출물(5.8).

### 4.4 이 서버(VM)와 GitHub

- Python 3.9.21. Node·Go·Java 없음. Docker 29 — Node·Playwright 이미지는 지금 없다(2026-10-14). Node 20 은 지원이 끝났으므로 22 이상으로 고정한다.

- GitHub: 이 문서를 쓴 VM 계정의 `gh` 가 저장소 주인 `hipiboy7` 로 로그인돼 있다(권한 `repo`). 이 서버의 시스템 git 설정이 `https://github.com/` 주소를 SSH 로 바꾼다(`url.…insteadOf`). 이 저장소에만 더 긴 접두사의 `insteadOf`(`https://github.com/hipiboy7/` → 자기 자신)를 두면 HTTPS 로 남고, `credential.helper` 를 `!gh auth git-credential` 로 두면 그 로그인으로 인증된다 — 2026-10-14 이 방법으로 첫 커밋(이 BRIEF·README)을 push 했다. 명령은 8절. 다른 VM 계정에는 이 로그인이 없다. 이 로그인은 저장소 관리자 권한이라 다른 계정에 넘기지 않는다(MWL `docs/dev/인수인계.md` 10.3).

## 5. 제안 구성 (착수 인터뷰·설계에서 확정)

### 5.1 학습이 먼저 (사용자 요청)

- **개발 순서**: 배우는 길(오늘·복습·강의·퀴즈·통계)을 먼저 완성해 사용자가 곧바로 공부를 시작하게 하고, 만들기(편집기·AI)는 그 위에 얹는다. **모든 Phase 는 사용자가 실제로 공부할 수 있는 결과로 끝난다**(5.9).
- **화면**: 첫 화면은 '오늘 학습'이다. 만들기·설정은 보조 메뉴다. MWL 화면 원칙 다섯(한 화면 기본 버튼 하나, 오늘은 순서 목록, 본문 먼저, 상태는 한눈에·색만으로 말하지 않는다, 메뉴는 묶어서)을 이어받는다.
- **첫날부터 배울 거리**: 만들기 기능이 없어도 MWL 미들웨어 과정과 Learn 자료로 시작한다. '프롬프트 복사' 입구(사내 AI 채팅 화면에 붙여 넣고 답을 붙여 넣기)를 AI API 연동보다 먼저 연다 — 그날부터 내 자료로 배울 수 있다.

### 5.2 세 판 — 같은 화면·같은 엔진, 판은 설정

| | 폐쇄망판 | 인터넷판(설치형) | 모바일판 |
|---|---|---|---|
| 여는 법 | 서버 모드: `py -3 -m <패키지> serve` → 브라우저. Python 이 없는 PC 는 HTML 더블클릭(`file://`) | 같음 | APK 설치 → 앱 아이콘 |
| 저장 | 파일(원자적 저장) · 브라우저 모드는 브라우저 저장소 | 같음 | 앱 저장소 + 파일 거울 |
| AI | 사내 2대 — **로컬 서버가 대신 부른다**(CORS 와 무관, 키는 파일) | 외부 AI — 같은 방식 | 없음(인터넷 권한 0) — 프롬프트 복사만 |
| 과정 만들기 | 넷 다(사내 자료 포함) | 넷 다(공개 자료) | 직접 작성 · 파일 가져오기 |
| 기록 이동 | **들여오기만**(합치기). 밖으로 내보내는 기능이 없다 — 백업·폐쇄망 PC 사이 이동만 | 폰과 양방향 합치기 · 폐쇄망으로 반입 | 집 PC 와 양방향 |
| 배포 | `.tgz` 반입(`tar -xzf`, 안 되면 반디집·7-Zip) | ZIP·`.tgz` | APK |

```
 집 PC(인터넷판) ⇄ 과정·기록 파일 합치기 ⇄ 폰(APK)
        │ 반입(.tgz) — 한 방향
        ▼
 폐쇄망 PC(폐쇄망판): 사내 자료로 만든 과정 · 안에서 쌓은 기록은 안에만
```

- 판 = 설정(AI 프리셋·허용 행선지·저장 어댑터·포장). 코드 분기를 두지 않는다. 폐쇄망판과 인터넷판은 같은 묶음이다.
- 알려 둘 한계: 안에서 한 복습은 밖에 반영되지 않는다(반출 불가의 대가) — 밖의 기기는 그 카드를 다시 낸다. 사내 자료로 만든 과정은 폐쇄망 안에서만 배운다.

### 5.3 핵심 설계 제안 (설계 검토 반영)

1. **계산은 JS 한 벌.** 화면은 어디서나 브라우저(WebView 포함)다. Python(3.9 표준 라이브러리 — 폐쇄망 PC 의 Python 판은 확인 전)은 로컬 서버(정적 파일·파일 저장·AI 대리 호출·문서 텍스트 뽑기)와 도구(변환·검사·포장)만 한다. 복습·계획·숙련도·통계·합치기는 JS 가 계산한다 — MWL 의 '엔진 두 벌' 위험이 없어진다. 예외 하나: 비밀값·실데이터 점검 규칙은 **JSON 한 파일(두 언어가 같이 읽는 정규식만) + 공통 대조 케이스**로 두 곳에서 쓴다(서버가 저장·대리 호출 때 다시 검사한다). 대가: MWL 의 CLI 학습 명령이 없다 — Claude Code 는 과정 파일을 만들어 넘기는 쪽으로 쓴다.
2. **기록은 기기별 사건 목록.** hub `events.py` 방식을 옮긴다: 사건 한 줄에 (기기, 순번, 시각, 학습일 `day`). 합치기 = 합집합 — 읽는 순서·중복·여러 번 들여오기와 상관없이 같은 결과(폐쇄망 '들여오기만'에 맞는다). 기기 ID 는 `crypto.getRandomValues` 로 만든다(`crypto.randomUUID` 는 보안 문맥에서만 된다 ⚠️ `file://` 에서 확인). 백업에서 되살린 기기는 새 ID 를 받는다.
   **늦은 복습 규칙**(검토에서 나온 가장 큰 결함): 폐쇄망 PC 와 폰은 같은 카드를 따로 복습한다. 사건을 시각 순으로 모두 적용하면 good 이 겹칠 때마다 간격이 ef 배(약 2.5배)씩 부푼다. → 다시 계산할 때 그 카드의 due 보다 이른 복습은 간격 계산에 쓰지 않는다(again 만 반영하고 나머지는 통계로 센다). MWL 골든 벡터는 늘 due 날에 복습하므로 그대로 통과해야 한다. 내일보다 뒤 날짜의 사건은 표시한다(기기 시계 오류).
3. **과정 = 파일.** 과정 파일(목차·강의 마크다운·카드·퀴즈·출처·신뢰도)과 기록 파일을 나눈다. 모든 파일 머리에 `{format, version, min_reader}`, 모르는 사건 종류는 지우지 않고 보존한다(폐쇄망 PC 는 옛 판일 때가 많다). 과정 항목 수정은 논리 시계(`updated = max(지금, 본 값 중 최대 + 1)` — 시계가 틀린 폰이 이기지 않게) + 고치기 시작한 판의 해시. 양쪽이 따로 고쳤으면 **둘 다 남긴다**. 지움 표시는 지우지 않는다. 기본 제공 과정은 읽기 전용이고 사용자 수정은 항목 ID·원본 해시로 따로 둔다. 원본 답이 정정되면 그 카드에 표시하고 다시 복습하게 한다.
4. **강의는 마크다운 원문, 화면이 그린다.** MWL `markdown.py` 를 JS 로 옮기되 그대로 옮기면 XSS 다 — 속성값을 이스케이프하지 않아 `![x" onerror="…](y)` 가 실행되고 `javascript:` 링크가 통과한다. → 속성값 이스케이프, 링크는 `http(s)`·`#` 만, 그림은 과정 파일 안의 것만, 서버 모드는 CSP 헤더. 시험: 135과를 MWL 렌더러 결과와 대조 + XSS 사례 모음.
5. **저장.** 기록은 덧붙이기(JSONL) + 하루 스냅숏 + 가져오기 전 백업(MWL 의 '백업 7개 회전'은 최근 7번 저장만 남긴다). 브라우저 저장은 월별 키로 쪼갠다(안드로이드 시제품의 저장 거울은 값을 통째로 다시 쓴다). 브라우저 저장 용량은 점검 도구로 잰다(5.8).
6. **AI 가 만든 것의 정직성.** 근거 대조 모델이 근거 문장을 인용하고 JS 가 그 인용이 자료 조각에 실제로 있는지 확인한다. 항목마다 모델·프롬프트 판·근거 조각을 기록한다. 복습 중 "이 카드가 틀렸다 → 보류" 단추를 둔다(간격 반복은 틀린 답도 강화한다). 주제만으로 만든 과정은 신뢰도 '미확인'으로 시작한다.
7. **판별 차이.** 폐쇄망 묶음은 외부 AI 프리셋을 빼고 외부 URL 0 을 검사한다. 안드로이드는 인터넷 권한 0.

### 5.4 통계 화면 (사용자 요청 · S7)

- MWL 의 통계·지도 화면과 차트 원칙(`docs/설계서_Architecture.md` 6.3 '색과 차트')을 가져와 **과정별·전체**로 넓힌다. 메뉴에서 바로 간다.
- 보여 줄 것(초안 — 인터뷰에서 우선순위를 정한다): 오늘·이번 주 학습 시간과 목표, 연속 학습일, 복습량과 정답률(good 이상) 추이, 정착률(카드별 최근 3회), 카드 상태 분포(새·배우는 중·정착·보류), 앞으로 7일 복습 예정, 과정·단원별 진도와 숙련도(L0~L5), 틀림이 많은 카드·단원, 점검(기준선) 학습 전·후, AI 가 만든 강의 중 사용자가 확인한 비율.
- 모두 사건 목록에서 JS 가 계산한다(합친 기록 기준). 폐쇄망 안의 통계는 '안 + 들여온 기록', 밖은 '밖의 기록'이다 — 화면에 그 범위를 적는다.
- 차트는 인라인 SVG, 외부 라이브러리 0, 색만으로 말하지 않는다, 값이 없으면 빈 축 대신 안내 문장, 폰 화면에서도 읽힌다.

### 5.5 폐쇄망 AI — 서버 여러 대 × 모델 여러 개

- AI 연결 = **서버 목록**(주소·키·형식) × **모델 프로필**(문맥 길이·답 상한·추론 강도·모델별 추가 요청 필드) × **용도 배정**(조각 요약·목차·강의·카드/퀴즈·근거 대조·메모 정리). `/v1/models` 로 목록과 문맥 길이를 읽는다(vLLM 은 `max_model_len` 을 준다고 알려져 있다 ⚠️ 확인 필요).
- 교차 검토: 쓴 모델과 다른 계열(OpenAI·Google·Alibaba 셋이 사내에 있다)이 근거 대조를 맡는다. 이중화: gpt-oss-120b 가 두 서버에 있다 — 한쪽이 안 되면 다른 쪽.
- 모델별 옵션: gpt-oss 는 `reasoning_effort`. Qwen 계열의 생각 모드 끄기 등은 모델·서버 판마다 다르다 → 프로필의 '추가 요청 필드'로 받고 현장에서 확인한다.
- 사내 자료는 보내되 **비밀값만 보내기 전에 가린다**: PEM 키·JWT·`sk-ant-`/`sk-proj-` 키·XML `<password>`·JEUS `{AES}` 값·URL 의 `user:pass@`·JDBC 계정, 개인정보(주민번호·Luhn 검사를 통과하는 카드번호·전화번호). 같은 값은 조각이 달라도 같은 자리표시로 바꾼다.
- 모델 용도는 앱 안 **'현장 비교' 화면**으로 정한다 — 같은 가상 자료로 모델마다 형식 통과율·시간·토큰·품질을 재서 짧은 결과 코드를 보인다. 개발자는 사내 모델에 닿지 못하므로 사용자가 그 코드를 말로 전한다.

### 5.6 긴 자료 처리 — 문맥이 작아도 매뉴얼 한 권을 과정으로

```
자료(붙여넣기·txt·md·DOCX/HWPX/PPTX)
 → 조각 나누기(제목 기준 약 4~8k 토큰 — 품질 기준. 한국어 번호 체계 '제n장'·'1.1'·'가.' 를 알아본다)
 → 조각마다 요점·용어·절차·수치 뽑기
 → 요점들이 문맥의 약 40% 를 넘으면 한 층 더 요약
 → 과정 목차(단원·강의, 강의마다 근거 조각 번호) → 사용자 확인
 → 강의마다 근거 조각만 넣어 본문·카드·퀴즈 생성
 → 근거 대조(다른 계열 모델): 근거 없는 문장 ⚠️ · 출처 = 자료 이름·절
```

- 길이 초과(서버 400)일 때만 조각을 반으로 나눠 다시 보낸다. 답 상한 문제면 답 길이를 줄인다. 토큰 수는 글자 수로 보수적으로 어림하고 점검 도구의 실측(글자/토큰)으로 맞춘다.
- 서버별 동시 호출 상한(공유 GPU — 1~2개), 작업을 취소하면 상류 호출도 끊는다, 용도별 시간 제한(MWL 의 180초는 짧다).
- 단계 결과는 `(입력, 프롬프트 판, 모델)` 해시로 저장한다 — 창을 닫았다 열면 같은 단계를 다시 돌리는 것으로 이어진다.
- 문서 파일 텍스트 뽑기: DOCX·HWPX·PPTX 는 ZIP 안의 XML 이라 서버 모드에서 Python 표준 라이브러리(`zipfile`·`xml`)로 뽑는다 — 제목·앵커를 남기고, `<!DOCTYPE` 이 든 XML 은 거부한다. PDF·HWP(바이너리)는 붙여넣기로 시작하고 인터뷰에서 다시 정한다.

Edge 의 `file://` 페이지들이 저장소를 함께 쓴다면 `mwl.progress` 를 바로 읽을 수 있다(⚠️ 점검 도구로 확인, MyLearner 의 키 접두사는 따로). MWL 의 `K0001-c01` 같은 내 지식 카드 ID 는 목록 위치에 기대므로 고정 ID 로 바꾼다. 이관 뒤 MWL 에서 계속 공부하면 기록이 갈라진다 → MWL 동결 시점을 정한다.
- 인터넷판 외부 AI: Anthropic Messages 형식(`x-api-key`·`anthropic-version` 헤더, `max_tokens` 필수, `system` 은 최상위, 답은 `content[]` 의 글 조각, `stop_reason: max_tokens` 면 잘림) + OpenAI 형식. 키는 로컬 서버에만 두고 브라우저로 보내지 않는다. 모델 기본값은 구현 때 공식 문서로 정한다.

### 5.8 첫 산출물 — 폐쇄망 점검 도구 2종 (착수 Phase 에서 가장 먼저)

사용자가 폐쇄망에 들고 가 돌리고, 결과를 **말로** 전한다(반출 불가). 결과 요약에는 주소·키·포트를 넣지 않는다.

- `tools/ai_probe.py`(만들 것) — Python 표준 라이브러리, 3.6 문법까지 호환(`ast.parse(..., feature_version=(3, 6))` 으로 시험).
  - Python 판·OS 를 먼저 찍는다. 서버 주소를 묻고 키는 화면에 보이지 않게 받는다(`getpass`). 호출은 하나씩, 호출 수 상한을 둔다.
  - 서버마다: 모델 목록·문맥 길이(`/v1/models` 의 `max_model_len` → 없으면 `/tokenize` → 길이 초과 400 메시지 → Ollama `/api/show`), `/version`·`Server` 헤더.
  - 모델마다: 한국어 약 6k 토큰 질문 1회(글자/토큰·처리 속도·조용한 잘림), `reasoning_effort` 를 low·high 로 보내 추론 토큰 차이로 실제 반영 여부 판정(200 응답만으로는 모른다 — T-007), `json_schema` 응답 형식 1회, `<think>`·`reasoning_content` 가 답에 새는지.
  - **리다이렉트를 따르지 않는다** — Python 3.9 의 `urllib` 는 리다이렉트 때 `Authorization` 헤더를 다른 호스트로 그대로 넘긴다(이 VM 의 3.9 원본 `redirect_request` 로 확인). 프록시를 쓰는지(Windows 레지스트리 프록시 포함) 알린다.
  - CORS 추정: 사전 요청(OPTIONS, `Origin: null`, `Access-Control-Request-Headers: authorization, content-type` — `Allow-Headers: *` 는 Authorization 을 덮지 못한다)과 실제 응답의 `Access-Control-Allow-Origin`. Python 은 Edge 정책·인증서·PAC 를 보지 못하므로 '추정'으로 적는다.
  - `--serve-test`: 127.0.0.1 에 작은 서버를 띄우고 Edge 로 연다(그 PC 에서 서버 모드를 써 본 적이 없다).
  - 한국어 Windows 콘솔에서 깨지지 않는 글자만 쓰고, 끝나면 멈춰 창이 바로 닫히지 않게 한다.
  - 시험(가짜 서버 `http.server`): 리다이렉트로 키가 새지 않음, `Allow-Headers: *`, 게이트웨이가 HTML 로 200, 401, 시간 초과, 길이 초과 400, 요약에 호스트·포트 없음.
- `tools/browser_probe.html`(만들 것) — 파일 하나, 외부 자원 0. Edge 의 localStorage·IndexedDB 용량, 브라우저를 다시 켠 뒤에도 남는지(종료 때 지우는 정책), `isSecureContext`, `file://` 페이지끼리 저장소를 나누는지.

## 8. 시작하는 법 · 이어 하는 법 (세션 유지)

같은 내용을 사람이 보기 쉽게 이 폴더의 `README.md` 에도 두었다.

**첫 세션** — 이 BRIEF 를 쓴 VM 계정으로 접속해서:

```bash
cd /data/projects/MyLearner && claude -n mylearner --model opus --effort max
```

첫 말:

```text
docs/BRIEF.md 를 기획으로 삼아, /data/projects/agentic-sdlc/docs/howtoUSE.md 를 읽고 그 순서대로 이 프로젝트를 시작해라.
이 폴더는 Learn 워크스페이스 밖이지만 /data/projects/Learn/CLAUDE.md 의 공통 규칙(경계 규칙·착수 절차)을 따른다 — 그 파일을 먼저 읽어라.
```

커밋 작성자는 이 저장소의 git 설정에 이미 들어 있다.

**이어 하기** — Claude Code 의 대화와 메모리는 **VM 계정 × 폴더** 마다 따로 저장된다. 반드시 같은 계정으로, 이 폴더에서 연다.

| 하고 싶은 것 | 명령 |
|---|---|
| 마지막 대화를 이어서 | `cd /data/projects/MyLearner && claude --continue` (또는 새로 열고 "이어서 하자" — CLAUDE.md 0-1절이 history 부터 읽게 한다) |
| 지난 대화 가운데 골라서 | `claude --resume` (목록에서 `mylearner` 이름으로 찾는다) |
| SSH 가 끊겨도 세션이 계속 돌게 | `claude --bg -n mylearner` → `claude attach mylearner`. 화면에서 ← 로 목록으로, Ctrl+Z 로 셸로 나가도 세션은 계속 돈다. 목록 `claude agents --cwd /data/projects/MyLearner`, 최근 출력 `claude logs mylearner`, 끝내기 `claude stop mylearner` ⚠️ SSH 를 끊었다 다시 붙어도 이어지는지는 처음 쓸 때 확인 |
| 같은 대화를 두 번째 창에서 갈라 이어 가기 | `claude --resume <세션ID> --fork-session` — 같은 폴더에서 두 번째 콘솔을 `claude -c` 로 열지 않는다(두 프로세스가 같은 대화 파일에 쓴다, Learn 루트 CLAUDE.md 1절) |

**GitHub** — 이 폴더에는 아래 설정이 이미 되어 있고 첫 커밋을 올렸다(2026-10-14). 새로 받은 사본에서만 다시 한다. 그 뒤의 push 는 사용자 확인 뒤:

```bash
# 이 폴더에는 이미 되어 있다 — 새로 받은 사본에서만(같은 VM 계정)
git -c url.https://github.com/hipiboy7/.insteadOf=https://github.com/hipiboy7/ -c credential.helper='!gh auth git-credential' clone https://github.com/hipiboy7/MyLearner.git
cd MyLearner
git config url.https://github.com/hipiboy7/.insteadOf https://github.com/hipiboy7/   # 시스템의 SSH 바꿔치기보다 긴 접두사 — HTTPS 로 남는다
git config credential.helper '!gh auth git-credential'                                  # 이 VM 계정의 gh 로그인으로 인증
git push
```
