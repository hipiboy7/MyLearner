## 1. 목적

Phase 2 의 계산 한 벌 위에 **PC 에서 공부하는 화면**을 올린다. 끝나면 사용자는 `.tgz` 를 풀어 `py -3 -m mylearner serve`(또는 `web/index.html` 더블클릭)로 열고, 미들웨어 과정과 Learn 자료로 '오늘 학습'을 하며, MWL 진도를 들여와 이어서 공부하고, 통계를 본다. 기록은 이 PC 에 남고 사라지지 않는다.

## 2. 범위

### 2.1 In Scope

- 화면: 오늘 · 복습 · 강의 · 실습 · 드릴 · 퀴즈 · 점검(기준선·무작위·오답 다시 풀기)·점검 기록·오답노트 · 과정 목록·지도 · 통계 · 용어 · 회고 · 설정 · MWL 진도 들여오기
- 저장 어댑터: 서버 모드(파일) · 브라우저 모드(localStorage 월별 키 + IndexedDB) — 같은 인터페이스
- 로컬 서버 `py -3 -m mylearner serve`: 정적 파일·기록·사용자 과정·백업 API, 접속 토큰, 보안 헤더
- core 더하기: 점검·오답노트(`checkup.js`), 통계 넓히기(`stats.js`), 렌더러의 링크 행선지 제한(판 설정)
- Learn 자료 변환기 `python3 -m mylearner.convert.learn`, 반입 묶음 `.tgz`(폐쇄망·인터넷판, 인터넷판은 ZIP 도)
- 시험: core·저장 어댑터 JS 단위, Python 단위·통합(실제 서버), 화면 스모크(Chromium — `file://`·서버 모드, 새로 고친 뒤 기록 남음), 접근성 검사, 묶음 재현·외부 URL

## 5. 제약

- MWL·Learn 은 읽기만 한다. 옮긴 코드의 머리에 출처와 기준 커밋을 적는다. 변환한 과정 자료는 `dist/`·`web/data/`(커밋하지 않음)에 만든다
- 개발 도구(Docker 이미지)는 이미 허락받은 셋(Node·Python 3.14·Playwright)만 쓴다. 접근성 검사에 npm 을 받지 않는다
- 사내 서버 주소·IP·계정을 문서·커밋에 쓰지 않는다

## 6. 완료 기준

1. `bash scripts/verify.sh` 가 새 단계(화면 스모크·접근성·Learn 변환·묶음)까지 모두 통과한다
2. 화면 스모크: `file://`·서버 모드에서 오늘 → 복습 → 강의 마침 → 통계가 돌고, 브라우저를 다시 연 뒤 사건이 같다. MWL 진도 들여오기가 N/N 일치를 보이고 두 번 들여와도 사건 수가 같다
3. 커버리지: JS `web/core/`·`web/store/` 순수 부분 ≥ 90%(A), Python A ≥ 90%·B ≥ 70%
4. 묶음: 두 번 만들어 같은 바이트, 폐쇄망판 앱 파일 외부 URL 0·내보내기 꺼짐
5. PC(1280px)·휴대폰(390px) 스크린샷을 테스트결과서 '화면 확인'에 두고 직접 봤다
6. 독립 점검: 저장 어댑터·서버(기록 유실·토큰·경로)의 지적을 원문으로 확인하고 처리했다(CLAUDE.md 12절 — 기록 유실이 걸린 곳)
