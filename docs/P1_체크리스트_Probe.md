# P1 체크리스트 — Probe (폐쇄망에서 점검 도구 2종 돌리기)

- 작성 2026-10-15 / 대상: 사용자(폐쇄망 PC) / 대응: [`P1_요구사항정의서_Probe.md`](P1_요구사항정의서_Probe.md) 6절 완료 기준 7, [`P1_테스트결과서_Probe.md`](P1_테스트결과서_Probe.md)
- 확인한 범위: 아래 명령은 이 VM(Linux)에서 `python3`·`tar` 로 같은 순서를 실행해 확인했다(2026-10-15). **Windows·Chrome 150 에서는 아직 실행하지 않았다** — 이 체크리스트가 그 첫 실행이다. 막히면 그 단계와 화면의 글을 피드백 칸에 적는다
- 걸리는 시간: AI 점검은 모델마다 몇 분(모델 5개면 10~30분 안팎으로 본다 ⚠️ 실측 전), 브라우저 점검 10분

## 0. 준비 — 개발 VM 과 내 PC

- [ ] 개발 VM 에서 묶음을 만든다
  ```bash
  cd /data/projects/MyLearner && python3 scripts/pack_probe.py
  ```
  → `만듦: /data/projects/MyLearner/dist/mylearner-probe-v1.tgz (… 바이트, sha256 …)` 이 보인다. sha256 앞 8글자를 적어 둔다
- [ ] 평소 VM 에서 파일을 받는 방법으로 `dist/mylearner-probe-v1.tgz` 를 내 PC 로 가져와, 반입 절차로 폐쇄망 PC 에 넣는다

## 1. 압축 풀기 — 폐쇄망 PC

- [ ] `.tgz` 가 있는 폴더의 탐색기 주소 칸에 `cmd` 를 치고 엔터 → 그 폴더에서 명령 프롬프트가 열린다
- [ ] 압축을 푼다
  ```bat
  tar -xzf mylearner-probe-v1.tgz
  cd mylearner-probe-v1
  ```
  → 폴더 `mylearner-probe-v1` 안에 `ai_probe.py`·`browser_probe.html`·`README_KO.txt` 세 파일. `tar` 가 안 되면 반디집이나 7-Zip 으로 푼다

## 2. AI 점검 — `ai_probe.py`

- [ ] 실행한다(`py` 가 없다고 나오면 `python ai_probe.py`)
  ```bat
  py -3 ai_probe.py
  ```
  → 첫 줄 `MyLearner AI 점검 도구 (결과 코드 판 1)`, 이어서 `Python 3.14.x, OS Windows 10.0.…`, `프록시 설정: …`
- [ ] `서버 주소(…)` 에 첫 번째 서버 주소를 적고 엔터(`http://` 를 빼도 된다), `키(화면에 보이지 않습니다…)` 에 키를 적고 엔터 → 글자가 보이지 않는 것이 정상이다
- [ ] 모델 목록이 나오면 엔터(전부) → `[S1M1 …] 긴 한국어 질문: 됨 (…초)` 같은 줄이 이어진다. 모델마다 몇 분 걸릴 수 있다
- [ ] 다시 `서버 주소` 가 나오면 두 번째 서버를 같은 방법으로 → 다 했으면 빈 줄에서 엔터
- [ ] `=== 결과 풀이 ===` 와 `=== 결과 코드 - …` 가 나온다 → 결과 코드는 `e …`, `s1 …`, `s1m1 …`, `s2 …`, `s2m1 …` 처럼 줄마다 끝이 `/두 글자` 다. 같은 폴더에 `ai_probe_result_<시각>.txt` 가 생긴다(같은 내용, 주소·키 없음)
- [ ] 이런 줄이 보이면 그대로 두고 다음으로 간다(결과 코드에 남는다): `TLS(인증서) 오류`, `프록시로 안 돼 직접 연결해서 됨`, `HTML 답(게이트웨이 화면)`. TLS 오류로 서버를 못 잰 경우에만 사내 인증서 파일로 다시 한다
  ```bat
  py -3 ai_probe.py --cafile 사내인증서.pem
  ```
- [ ] 엔터를 눌러 창을 닫는다(결과는 위의 txt 파일에 남아 있다)

## 3. 브라우저 점검 — `browser_probe.html`(더블클릭, file://)

순서가 중요하다 — 한 번에 하나의 결과 코드로 '다시 연 뒤 남는가'와 '사본끼리 공유'를 따로 가른다.

- [ ] MWL 화면(MWL 이 열린 크롬 탭)을 모두 닫는다
- [ ] `browser_probe.html` 을 크롬으로 연다(엣지로 열리면 파일을 크롬 창에 끌어 놓는다) → `자동 점검을 마쳤습니다…`. `MWL 기록이 이 저장소에 있습니다` 가 보이면 `MWL 을 닫았다 - 용량 시험 시작` 을 누른다 → `용량 시험을 마쳤습니다`
- [ ] 크롬 창을 **모두** 닫는다(작업 표시줄·알림 영역의 크롬까지). 크롬을 다시 열고 같은 `browser_probe.html` 을 다시 연다
- [ ] `다시 열었다 - 남았는지 확인` 을 누른다 → 표의 `다시 연 뒤 남음` 이 `남음` 또는 `사라짐 있음`. 크롬이 탭을 되살려 `정말 … 다시 열었습니까?` 가 뜨면 `확인`
- [ ] `browser_probe.html` 을 바탕 화면에 복사해 그 사본을 새 탭으로 연다 → 점검이 끝나면 그 탭을 닫는다
- [ ] 원래 탭으로 돌아와 `다른 폴더의 사본을 먼저 열었다` 를 누른다 → `file:// 사본끼리 공유` 가 `함께 씀` 또는 `따로 씀`
- [ ] `클립보드에 써 보기` 를 누른다 → `클립보드 쓰기` 가 `됨`·`옛 방식만`·`안 됨`(원하면 메모장에 붙여 `MyLearner 점검 …` 이 나오는지 본다)
- [ ] `내려받아 보기` 를 누르고 다운로드 폴더에 `mylearner_probe.txt` 가 생겼는지 본 뒤 `받아졌다` 또는 `안 받아졌다`
- [ ] (선택) `AI 서버 주소` 에 첫 번째 서버 주소를 적고 `시험` → `끝났습니다`, `AI 서버에 직접` 칸에 값이 생긴다(키는 넣지 않는다)
- [ ] 화면 위 `결과 코드` 상자의 `b …` 한 줄을 옮겨 적는다(손으로 하는 점검을 하면 바뀐다 — 마지막 것)

## 4. 서버 모드 점검 — `--serve-test`(http://127.0.0.1)

- [ ] 명령 프롬프트(`mylearner-probe-v1` 폴더)에서
  ```bat
  py -3 ai_probe.py --serve-test
  ```
  → `시험 서버를 띄웠습니다(이 PC 안에서만 열립니다).`, `크롬에서 이 주소를 여세요: http://127.0.0.1:8770/?t=…`. 브라우저가 저절로 열린다 — 엣지로 열리면 그 주소를 복사해 크롬에 붙인다
- [ ] 페이지의 `서버 모드` 칸이 `됨`(쿠키 됨, 큰 POST 됨) → 명령 프롬프트에 `브라우저 결과 코드: b … g=h …` 가 찍힌다
- [ ] (선택) 이 페이지에서도 5번 AI 서버 시험을 한다(file:// 와 출처가 다르다)
- [ ] 명령 프롬프트에서 엔터 → `받은 브라우저 결과 코드:` 아래 줄들 → 마지막 `b …` 한 줄을 옮겨 적는다 → 엔터로 닫는다

## 5. 정리와 전달

- [ ] 3번 페이지와 4번 페이지 각각에서 `흔적 지우기` → `지웠습니다.`(두 출처의 저장소가 따로라 둘 다 누른다)
- [ ] 옮겨 적은 줄을 이 대화에 붙인다: `e`, `s1`·`s1m…`, `s2`·`s2m…`, `b`(file://), `b`(http). 끝의 `/두 글자` 까지. 대문자로 적어도 된다
- [ ] (개발 쪽이 한다) 받은 줄을 풀어 검사합을 확인한다
  ```bash
  python3 tools/ai_probe.py --decode "e v=1 p=3.9.21 o=l5.14 q=n a=n s=2 /c4"
  ```
  → 줄마다 `검사합 맞음` 이면 P1 테스트결과서 10절에 옮기고 보류 결정 7 을 닫는다. `검사합이 맞지 않습니다` 면 그 줄만 다시 본다
