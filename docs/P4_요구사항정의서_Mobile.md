## 1. 목적

Phase 3 의 PC 화면을 **폰 앱**에 그대로 싣고, 세 곳(폰·내 PC·폐쇄망 PC)의 기록을 **파일로 합친다**. 끝나면 사용자는 GitHub 앱에서 APK 를 받아 설치하고(S4), 폰에서 미들웨어 과정·Learn 자료를 배우고 복습하며(S6·S7), 폰 기록을 내 PC 와 합치고, 그 결과를 zip 하나로 폐쇄망 PC 에 들여온다. 어느 길로 몇 번을 오가도 기록은 하나도 사라지지 않는다(S3).

```
 폰(APK, 모바일판) ── 교환 파일(zip) ──▶ 내 PC(인터넷판) ── 교환 파일(zip) ──▶ 폐쇄망 PC(폐쇄망판 — 들여오기만)
        ◀── 교환 파일(zip) ──
```

## 2. 범위

### 2.1 In Scope

- 안드로이드 앱(APK): WebView 껍데기, 인터넷 권한 0, 새 패키지 이름·서명 키, 앱 안 과정 셋(PC 묶음과 같음)
- 안드로이드 저장 어댑터: 앱 전용 파일에 원자적으로 — Phase 3 저장 어댑터 인터페이스 그대로
- 교환 파일: 모든 기기 기록 + 사용자 과정을 zip 하나로. 폰·인터넷판은 내보내고, 세 판 모두 들여온다
- 합치기 화면: 파일 고르기 → 미리보기 → 확인 → 자동 백업 → 합침 → 확인(N/N). 되돌리기·백업에서 되살리기
- 폐쇄망판 묶음 zip(`.tgz` 도 함께), 폰에서 MWL 진도 들여오기, 폴드5 두 화면
- CI(GitHub Actions) 2종: Windows 러너의 묶음 실기, Linux 러너의 안드로이드 에뮬레이터 시험
- 릴리스 `v0.4.0`: APK + 폐쇄망 zip 포함(CLAUDE.md 7절 '릴리스')

### 2.2 Out of Scope

| 빼는 것 | 가는 곳 |
|---|---|
| 카카오톡 등에서 받은 파일을 '이 앱으로 열기'(공유받기·연결 프로그램) — 앱 안 '파일 고르기'로만 연다 | 피드백이 오면 Phase 7 |
| 같은 ID 사용자 과정의 항목 단위 합치기(교환 파일의 과정이 지금 것과 다르면 지금 것을 둔다) | Phase 5(과정 편집) |
| 기기 이름 붙이기 — 기기는 ID 와 그 파일을 만든 판으로만 보인다 | 피드백이 오면 |
| 폰의 AI 연결(인터넷 권한 0) | 하지 않음(BRIEF 5.2) |
| 스토어 등록·자동 업데이트·푸시·계정 | 하지 않음(scope 10절) |
| iOS | 하지 않음(scope 10절) |
| MWL 저장소의 안드로이드 앱 고치기 | 하지 않음(P4 인터뷰 4절 3번) |

## 5. 제약

- MWL 은 읽기만 한다. 옮긴 코드의 머리에 출처와 기준 커밋(`e55b9c0`)을 적는다
- 개발 도구는 허락받은 것만: 빌드 이미지 `ghcr.io/cirruslabs/android-sdk:36`, 에뮬레이터 시스템 이미지(`/data`, 받기 전에 `df -h /data`), Playwright·Node·Python 3.14 이미지(CLAUDE.md 11절)
- Actions 에서는 MWL(private)·Learn 자료를 읽지 못한다 — 실데이터가 필요한 단계는 VM 에서만
- 서명 키는 VM 에서만 쓴다. Actions 는 실행 때 만든 시험 키로만

## 6. 완료 기준

1. `bash scripts/verify.sh` 가 새 단계(교환 파일·합치기 시험, APK 빌드·권한 점검, 워크플로 정적 검사)까지 모두 통과한다
2. 폰 흐름: APK 를 설치해 오늘 → 강의 → 복습 → 통계가 돌고, 교환 파일을 내보내 내 PC 에 합치면 N/N, 그 PC 의 교환 파일을 폐쇄망판에 들여오면 N/N — 화면 스모크(Chromium, 폰 폭)와 에뮬레이터 시험(Actions 또는 VM)
3. 커버리지: JS `web/core/`·`web/store/` 순수 부분 ≥ 90%(A), Python A ≥ 90%·B ≥ 70%, Java 규칙 시험(JVM)
4. CI 2종이 GitHub Actions 에서 한 번 이상 초록으로 끝났고 그 실행을 테스트결과서에 적었다(KVM 이 안 되면 그 사실과 대안)
5. 폰 폭 스크린샷(390px·폴드 두 폭)을 테스트결과서 '화면 확인'에 두고 직접 봤다
6. 독립 점검: 합치기·되살리기·교환 파일 읽기(기록 유실·zip 입력)를 원문으로 확인하고 처리했다(CLAUDE.md 12절)
7. 체크리스트 `P4_체크리스트_Mobile.md` — 폰 점검 순서(MWL `docs/checklist/android-app.md` 를 본뜸)·폐쇄망 반입
