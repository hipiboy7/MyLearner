## 1. 개요

무엇이든 내가 넣은 자료로 강의·카드·퀴즈를 만들고, 매일 배우고 복습해 몸에 익히는 **1인용 학습 플랫폼**이다. 폐쇄망 PC·내 PC·안드로이드 폰에서 같은 화면으로 배우고, 기록은 파일로 합친다.

- 사용자 = 학습자 = 설치·운영자. 1명이고 계정·서버는 없다
- 출발점은 MiddlewareLearner(MWL, `/data/projects/MiddlewareLearner`)다. 하루 루프·숙련도·사실 정직성·실데이터 점검을 복사해 고쳐 쓰고, MWL 에 의존하지 않는다. 물려받을 것과 그대로 못 쓰는 것은 BRIEF 4.1
- MWL 미들웨어 과정은 기본 제공 과정 하나가 된다. Learn 자료(콘텐츠 표준 v0)도 과정으로 가져온다(BRIEF 4.2)

## 3. 핵심 개념

- **판 = 설정**: 폐쇄망판·인터넷판·모바일판은 같은 화면·같은 엔진이다. AI 프리셋·허용 행선지·저장 어댑터·포장만 다르고 코드 분기는 없다(BRIEF 5.2)
- **계산은 JS 한 벌**: 복습·계획·숙련도·통계·합치기는 JS 가 한다. Python 은 로컬 서버(정적 파일·파일 저장·AI 대리 호출·문서 텍스트 뽑기)와 도구만(BRIEF 5.3-1)
- **기록 = 기기별 사건 목록**: 합치기는 합집합이다. due 보다 이른 복습은 간격 계산에 쓰지 않는다(늦은 복습 규칙, BRIEF 5.3-2)
- **과정 = 파일**: 과정 파일과 기록 파일을 나눈다(BRIEF 5.3-3)
- **입구 다섯·관문 하나**: 자료 → AI 정리, 주제 → AI 생성, 직접 작성, 파일 가져오기, 프롬프트 복사. 모두 비밀값 점검 → 양식 해석 → 과정 검사 → 저장을 지난다(BRIEF 5.7)
- **폐쇄망은 들여오기만**: 안에서 쌓은 기록·과정은 밖으로 나가지 않는다. 안에서 한 복습은 밖에 반영되지 않는다(BRIEF 5.2)

## 5. 데이터 전략

- 과정 파일과 기록 파일을 나눈다. 모든 파일 머리에 `{format, version, min_reader}` 를 둔다. 모르는 사건 종류는 지우지 않고 보존한다(BRIEF 5.3-3)
- 기록은 덧붙이기(JSONL) + 하루 스냅숏 + 가져오기 전 백업이다. 브라우저 저장은 월별 키로 쪼갠다(BRIEF 5.3-5). 방식과 한도는 Phase 1 점검 결과로 정한다(보류 결정 7)
- 민감 정보: 사내 자료는 사내 AI 로만 보내고, 보내기 전에 비밀값을 가린다(BRIEF 5.5). 과정 파일·문서·커밋에 실운영 자료를 넣지 않는다. 폐쇄망 안에서 만든 과정은 안에만 둔다
- Learn 자료는 `area: kids` 를 가져오지 않는다. 같은 자료는 hub 와 MyLearner 가운데 한쪽에서만 복습하도록 안내한다(BRIEF 4.2·5.7)

## 6. 설계 방향

BRIEF 의 다음 절을 따른다: 5.3 핵심 설계 7개, 5.4 통계, 5.5 폐쇄망 AI, 5.6 긴 자료 처리, 5.7 과정 만들기, 5.8 점검 도구. 바뀐 것은 11절에 있다. 모듈 구조·디렉토리·화면 기준은 [`설계서_Architecture.md`](설계서_Architecture.md) 에 둔다.

## 7. 성공 기준

- 2절 S1~S7 을 각 판정 방법으로 통과한다
- 모든 Phase 가 사용자가 실제로 공부할 수 있는 결과로 끝나고, 사용자가 그 Phase 체크리스트로 써 보고 피드백을 준다
- 전체 검증 명령 하나(`bash scripts/verify.sh`)가 종료 코드 0 으로 끝난다

## 10. Scope

**In**: BRIEF 5절 전체 — 세 판(폐쇄망·인터넷 설치형·안드로이드), 배우는 길(오늘·복습·강의·퀴즈·점검·통계), 과정 만들기 입구 다섯, 기록 합치기, MWL 과정·진도 이관, Learn 자료 가져오기, 폐쇄망 AI(서버 여러 대 × 모델), 외부 AI, 점검 도구 2종.

**Out**: 아이폰·앱스토어·PWA, 여러 사용자·계정·서버, 폐쇄망 밖으로 내보내기, MWL·hub·Learn 루트 고치기(읽기만 한다), `area: kids` 자료, 학습가이드·작업 프롬프트·프로토타입(인터뷰 3~5번).
