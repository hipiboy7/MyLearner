## 1. 요약

- 통계는 BRIEF 5.4 를 모두 넣고, 순서는 ① 오늘·이번 주 학습량과 목표·연속 학습일·앞으로 7일 복습 예정 → ② 복습량·정답률 추이 → ③ 카드 상태 분포·정착률 → ④ 과정·단원별 진도와 숙련도 → ⑤ 틀림이 많은 카드·단원 → ⑥ 점검 전·후. 'AI 가 만든 강의 확인 비율'은 값이 생기는 Phase 6 에서 넣는다(1번)
- MWL 과 MyLearner 는 **한동안 병행**한다(2번). 들여오기를 여러 번 해도 되게 만들고, 들여온 상태가 그 진도의 마지막 복습일까지 MyLearner 쪽 복습을 덮는다는 것을 들여오기 화면에 적는다. 동결 시점은 정하지 않는다
- 저장은 **서버 모드 = 파일, `file://` = localStorage 월별 키(기록) + IndexedDB(큰 것)**, 저장 어댑터 뒤에 둔다(3번). 폐쇄망 점검 결과(보류 결정 8)가 오면 확정하거나 바꾼다 — 잠정 결정
- 내 PC 는 **폐쇄망 PC 와 같은 범위**(Windows · Python 3.9 이상 · Chrome)로 본다(4번). 다르면 체크리스트 피드백으로 고친다
- 사용자 지시(같은 날): 체크리스트 피드백을 기다리지 않고 진행한다. Phase 4 용 안드로이드 빌드 이미지를 받아 `/data` 에 둔다(CLAUDE.md 11절 '허락받은 것', `scripts/dev_tools.env` `ANDROID_IMAGE`)
